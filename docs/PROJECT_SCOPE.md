# BanglaGuard Project Scope

## Primary research task

Robust and explainable hate-speech detection for:

- Native Bangla
- Romanized Bangla or Banglish
- Bangla-English code-mixed text
- Noisy and intentionally obfuscated social-media text

## Secondary module

Bangla sentiment analysis:

- Positive
- Negative
- Neutral

## Future work

- Fake-news detection
- Emotion classification
- Cyberbullying detection
- Moderation recommendation

## Core research questions

1. How do classical and transformer models compare?
2. How well do models generalize across scripts and datasets?
3. How robust are they to spelling and character-level noise?
4. Can explanations support human review?

## Version 1 exclusions

BanglaGuard will not:

- Automatically punish users
- Make legal decisions
- Claim that predictions are objective truth
- Collect private messages
- Store unnecessary personal information
